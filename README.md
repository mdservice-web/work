# MD Service Work

Partner / referral website for [MD Service](https://mdservice-web.github.io/web/).

**Offer:** Aap Client Lao, Project ka 20% Aapka.

## Public pages

- `index.html` — home, services, commission calculator, how it works, FAQ, contact
- `join.html` — partner application form
- `rules.html` — partner rules
- `privacy.html` / `terms.html`

Public contact: **mdservice.in@gmail.com**  
Private WhatsApp number is not used on this website.

## Go live

1. Upload these files to a GitHub repo.
2. Enable GitHub Pages (branch `main`, folder `/`).
3. Follow `SETUP.md` to connect the form to your private Google Sheet + email.

Until `config.js` has the Apps Script Web App URL, the form still emails `mdservice.in@gmail.com` (FormSubmit). After you paste the Web App URL, submissions go to the Sheet **and** email.
